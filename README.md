# Vehicle Sales Dashboard

Esta aplicación web permite explorar datos de anuncios de venta de vehículos.

El proyecto fue desarrollado utilizando Python, Pandas, Plotly Express y Streamlit.

## Funcionalidades

- Histograma de la distribución del kilometraje de los vehículos.
- Gráfico de dispersión para analizar la relación entre kilometraje y precio.
- Controles interactivos mediante casillas de verificación.

## Dataset

El proyecto utiliza el archivo `vehicles_us.csv`, que contiene información de anuncios de vehículos.

## Ejecución local

Para ejecutar la aplicación:

```bash
streamlit run app.py
```
